# color balance (deprecated) (colorbalance)
group: color | deprecated | typical position: legacy stacks only
synonyms: color balance, lift gamma gain, slope offset power, color grading, deprecated, legacy, cdl, shadows tint
purpose: The deprecated lift/gamma/gain and slope/offset/power colour grading module,
  superseded by color balance rgb.
use_when: only for legacy history stacks; use color balance rgb, which adds perceptual
  saturation controls, luminance masks and far better gamut behaviour.

# highpass (highpass)
group: sharpness | display-referred | typical position: late, blended
synonyms: high pass, sharpening, blend overlay, edge detail, structure, unsharp, frequency separation, crisp
purpose: Extracts the high-frequency (fine detail) component of the image; on its own
  it produces a gray image with edges, and it is designed to be combined with
  the original via a contrast blend mode such as overlay or soft light.
use_when: you want the classic high-pass sharpening technique with full control via
  blend mode and opacity; diffuse or sharpen and contrast equalizer are usually
  better modern choices.

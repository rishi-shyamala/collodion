# rotate pixels (rotatepixels)
group: geometry | raw | typical position: raw stage, before demosaic
synonyms: rotate pixels, sensor rotation, tilted sensor, fuji, technical rotation, raw geometry, non aligned sensor
purpose: Rotates the raw pixel grid by a camera-specific angle for sensors that are not
  mounted square to the image frame. It is auto-applied for the affected cameras
  and is a technical correction, not a creative one.
use_when: you are working with a camera whose sensor is rotated relative to the frame
  (certain Fujifilm and specialised bodies); otherwise leave it alone.

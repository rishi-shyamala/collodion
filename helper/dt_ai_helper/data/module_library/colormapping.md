# color mapping (colormapping)
group: color | display-referred | typical position: after tone mapping
synonyms: color transfer, match colors, palette transfer, copy look, source image, cluster colors, match another photo
purpose: Transfers the colour palette of a source image onto the target image by
  matching statistical colour clusters.
use_when: you want one photograph to adopt the colour character of another; you are
  matching a series to a reference frame. Results are unpredictable on images
  with very different content.

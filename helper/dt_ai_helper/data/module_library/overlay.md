# composite (overlay)
group: effect | any | typical position: late, creative stage
synonyms: composite, overlay image, texture overlay, watermark alternative, blend another image, double exposure, paper texture, light leak
purpose: Composites a second image file over the current one, with controls for scale,
  rotation, position and blending, so textures, light leaks or double-exposure
  elements can be layered in.
use_when: you want a paper or grunge texture, a light-leak overlay, or a simple double
  exposure; a logo or graphic needs compositing more flexibly than the watermark
  module allows.

# raw chromatic aberrations (cacorrect)
group: correction | raw | typical position: raw stage, before demosaic
synonyms: chromatic aberration, ca, fringing, raw ca, bayer, lateral aberration, purple fringe, color fringe
purpose: Automatically corrects transverse (lateral) chromatic aberrations directly on
  Bayer raw data, before demosaic, without needing a lens profile.
use_when: coloured fringes appear along high-contrast edges toward the frame corners on
  a Bayer raw file and you have no lensfun profile; use chromatic aberrations
  (cacorrectrgb) for X-Trans files, for non-raw files, or for residual fringing.
